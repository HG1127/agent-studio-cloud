# 最终交付字段选择

最终交付可以从业务步骤的结构化成果中选择具体字段，组合并重命名；不是只把整个步骤对象复制出来。配置目前通过助手定义导入或既有后端流程保存入口使用，画布尚无专用来源字段编辑器。没有新增执行接口，不改变任务结果读取和成果投递协议。

## 配置示例

以下是流程或冻结版本的 `outputContract`。`sourceNodeId` 指定业务步骤，`sourcePath` 是从该步骤实际输出开始读取的字段数组，`path` 是最终成果中独立的目标位置。

```json
{
  "fields": [
    { "path": "交付.金额", "label": "订单金额", "required": true, "sourceNodeId": "extract", "sourcePath": ["rows", "0", "amount"] },
    { "path": "交付.批准", "label": "业务决定", "required": true, "sourceNodeId": "extract", "sourcePath": ["rows", "0", "approved"] },
    { "path": "交付.邮箱", "label": "业务邮箱", "required": true, "sourceNodeId": "extract", "sourcePath": ["rows", "0", "email"] }
  ]
}
```

步骤成果如下，其他中间内容不自动交付：

```json
{
  "extract": {
    "rows": [{ "amount": 0, "approved": false, "email": "business@example.com" }],
    "other": "未选择的中间内容"
  }
}
```

最终成果如下，零金额、否定值和业务邮箱都是真实值：

```json
{ "交付": { "金额": 0, "批准": false, "邮箱": "business@example.com" } }
```

## 来源与发布

- 主流程选择原步骤标识；顺序子流程选择完整内部标识，如 `group.extract`；并行选择完整容器、分支、步骤标识，如 `batch.work.extract`。不要手写汇总数组序号或从模型 JSON 猜测来源。
- 发布、保存、启动、导入和历史恢复沿用同一来源校验。内部来源必须属于实际配置的合法容器；启动、结束、隐藏容器及内部隐藏控制步骤不能作为业务来源。设计审计识别同样的来源。
- 运行只使用冻结版本的字段配置和来源定位。顺序容器须已完成，并行容器须完成或带问题完成且所选分支成功；失败、等待或未执行的来源不能交付已有半成品。明确存在但为空的平铺来源不会回退旧汇总。
- 新路径改变版本指纹；后改草稿不改变原版本。导出后再导入保留字段选择。失效的具体字段不能由安全修复自动猜测新的步骤，需重新选择业务来源和字段。

## 读取与容量边界

- 每个来源路径最多 32 段，每段最多 200 字符。含点字段名按数组中原名读取；数组只读取从零开始的规范索引，不读取 `01`、负数、数组长度、方法、继承字段或访问器。不支持通配符、筛选或表达式。
- 有来源路径时必须明确来源步骤；`sourcePath: []` 选择整个步骤输出。省略 `sourcePath` 保留已有整步交付，且不会给旧字段补出默认路径；省略来源步骤的旧目标路径读取行为保留。无任何交付字段仍沿用原成果行为。
- 必填缺失列出业务名称，整个任务失败且不返回半成品；可选缺失省略。空白、空对象和空数组保持原缺失语义，零和否定值不算缺失。无效 JSON 即使可选也明确失败，不偷偷丢弃或截断。
- 所选字段和最终组合成果都受 2MB、32 层嵌套及 50000 项内容限制，按实际 UTF-8 字节逐字段组装核对，超限立即停止读取和复制后续字段；每个交付契约最多 100 个字段。目标仍是命名对象路径，不支持写入数组索引。
- 只读取所选字段，不执行 getter 或 toJSON。选中的 JSON 复制后交付，不修改或别名引用原上下文。过程成果仍保留在运行上下文，不因最终选择被平铺、复制进最终结果或删除。

## 凭据边界与验收

禁止保留名称和已识别凭据来源字段，例如 `password`、`apiKey`、`access_token`、`密钥`，不能通过把它们重命名为业务字段绕过脱敏；可选字段也不能选择。业务邮箱和 `input_tokens` 等用量字段不被当作凭据。整对象交付继续保留原有结果读取、报告和投递的凭据隐藏策略；这些规则不保证识别任意业务秘密。

编排层只传冻结字段和选中来源定位，字段计算在运行收尾步骤调用纯领域函数后复用原完成写入；校验失败是永久失败，不写完成状态或启动验收，原重试对账与取消保护保持不变。契约、领域、安全修复、发布门禁及完整示例由普通测试验证。真实数据库冻结版本、实际 SDK 容器到最终成果与任务接口读取的用例只交给 CI 临时 Neon 空库，本地不在共享或生产库执行。常规测试及构建不能替代本次精确提交的隔离验收，也不能替代真实供应商和业务联合验收。
