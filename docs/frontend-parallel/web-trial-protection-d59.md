# 网页内部试运行离开与迟到回执保护

独立前端工作树 `codex/frontend-tool-registry-details-d59`；前像为冻结 Root35 共同569，清单 SHA `4474365411D8CA699AB5D6F798473CD669CD1782095A89FA55282302B1753392`。本包不修改旧 V5.7、后端、共享契约、数据库、依赖或 CI 配置。

## 产品对照与实际接线

旧 `WebToolPreviewPane.handleSimulateRun` 同时存在真实公开接口尝试与失败后的模拟交付生成。本轮只沿用现有云端 `startRunAction` 和 `RunStartInput` 内部真实任务能力，不复制模拟成果，不称网页已发布。接口使用提交时当前正式版本，没有版本锁定字段。

真实 `WebToolReadiness` 的更换版本表单标记由 `WebToolTrialProtection` 捕获。创建中或结果未知时，普通当前窗口链接与版本提交须确认离开；关闭/刷新使用浏览器原生提醒。锚点、下载、组合键和新标签不误拦截。浏览器后退的单页导航不能由 `beforeunload` 保证拦截；历史地址变化只撤销旧请求自动导航资格，不改浏览器历史或冒充已阻止离开。

确认离开只改变本页导航资格，不取消后台动作，不清空待核对原请求、不自动重试。当前页仍可收到真实回执，但不能自动把用户带回旧任务；保留手动详情入口。归属按助手与版本建私有会话键，生命周期代次和卸载检查阻止 A→B→A 的旧成功、未知或明确失败污染新会话。

创建互斥、已创建回执和未知状态使用同步引用，与准备输入和父表单锁定同步。未知核对沿用原完整请求对象、请求标识和输入；再次核对失败仍不能推断未创建。成功才解除输入保护，并保留“已创建不等于完成”的真实回执，不开放再次创建同一次任务。

## 规格与未完成验收

新增 `web-tool-trial-protection-composition.test.tsx` 使用实际正式来源父组件与真实试填/确认叶子，仅替换 Server Action 和路由边界的延迟返回。覆盖同批次锁定、未知固定请求、更换版本与记录入口取消离开、确认离开后迟到回执、归属 ABA 三种返回、卸载、历史变化、新标签/下载/锚点及 StrictMode 生命周期。

`web-tool-trial-desktop.spec.ts` 新增真实创建与发布后，向真实 Server Action 发出原请求、读取真实响应但丢弃浏览器回执的原生路径。确认未知、取消离开、同请求恢复，再核对真实报告输入/版本和仅一条任务记录；不以模拟成功替代创建。原正常运行→审批→结果回看规格保留。

仅编写上述规格，未在 Root 执行安装、typegen、类型、lint、Vitest、build、Playwright 或完整验收。旧冻结565的有限全绿不覆盖本包；其他失败历史保持。Git/CI 专用对话后续针对最终合并同代码执行 `pnpm acceptance`，隔离 Neon/Workflow、完整门槛及可访问预览均未证明。

## 保留的接口需求

固定版本启动、按幂等请求标识重新读取确定回执、跨刷新/设备恢复原请求、独立网页定义/发布/凭据/公网访问/访问限额仍缺真实接口。离开保护不替代这些后端能力。
