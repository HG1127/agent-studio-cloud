新 WebToolRunUpdates 直接复用任务详情的 useRunStream，以及真实 GET /api/runs/[runId]/events。只消费 RunView 的 id/status，标识和状态通过已有契约核对，不传原输入、运行结果、步骤错误或工具凭据。它只在 WebToolTrialResult 验证内部手动任务和同助手版本归属后由 WebToolSavedRun 挂载。

排队、执行、等待确认和等待补充消息时尝试自动读取。事件/结束只触发 router.refresh 重读实际保存状态，不按事件标题宣布完成；已有失败、取消或完成终态不连接。直接复用现有断流低频重读，无新自建运行或审批恢复轮询器。错误/非法结束不当作任务完成，不启动或批准任务。

用户可暂停/恢复本页更新；暂停清理 EventSource 与已有低频重读，不取消业务任务、不发写操作。任务身份变化按真实id重新挂载，旧事件和定时器不影响新任务，卸载清理；暂停状态只在页面内存，无浏览器存储。终态来自服务端页重新读取后才移除更新区，历史结果槽和完整输入覆盖不变。
