## 实际实现

- 交付定义分别编辑最终位置、明确来源和来源子字段。子字段以字面层级数组保存；含点字段不拆分，列表位置从零开始。旧缺省与空数组保持整步语义，读取不自动写默认值；切换来源保留原层级并提示重新核对。单层名称长度、层级边界、保留名称复用 InputSourcePath；整项凭据、来源与位置检查复用真实 validateOutputContract，不在浏览器重写投影器。
- 来源清单复用 workflowOutputSourceNodes、prepareSubflow、prepareParallelBranches，包含运行时真正接受的子步骤。上下文显示业务名称，定位实际所属画布步骤；不通过标识前缀猜测归属。隐藏或未被准备器接受的组不制造子来源，未知原定义保留提示。检索支持来源上下文和子字段，只有同一来源且同一字面路径才提示重复取值。
- FlowCanvas 保存采用已有完整交付校验，修复仅认顶层节点导致拒绝合法组内来源的问题。原动作、保存修订号及不确定请求重试机制保留。删除或改组类型精确移除有效依赖的交付定义，不按前缀删未知来源；确认前预告类型切换影响，草稿变化拒绝旧确认。改动沿用撤销重做。
- 并行网页对话交付的四文件只读试算增量保持原 SHA 不变。父组件传完整当前草稿和当前交付实际引用的合法来源，不补样例或缺失流程；输入只留组件内存。调用固定本站 POST /api/workflows/output-preview，解析唯一 Input/Result，executed:false。真实纯 RouteHandler/query 组合验证组内来源、含点字段、列表零下标、零和否。任何试算都不是运行、交付质量或来源实际执行的证明。
- 提交快照与当前定义分开，草稿或参考值变化后结果永久过期，即使恢复原配置也不重新采用；晚响应舍弃。可取消、明确确认清除、失败保留原填写，不自动重发、不写浏览器存储、不调用保存或启动动作。原始结构仅在开发者区核对。
