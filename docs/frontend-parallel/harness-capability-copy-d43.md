# 运行控制台能力边界文案修正

本增量只修正实际 d43 后端上的能力说明，不实现新的运行策略，也不修改读取、筛选或资源写入流程。

## 真实能力与接口缺口

- `server/steps/harness-policy-step.ts` 的执行策略检查会保存 `harness.policy` 事件；`server/steps/model-step.ts` 的上下文边界检查会在超限或配置无效时保存 `harness.context` 事件。现有运行轨迹查询和前端分类已支持这些已保存事件。
- `contracts/run.ts` 的 `TraceEventView` 不含完整规则标识、判决数据或实际上下文预算数字。事件不能替代完整规则判决，成功读取空清单也不能证明没有发生检查。
- 当前资源设置读取、修改和变更历史是独立真实能力，不能与旧版完整默认策略编辑器混为一谈。
- 完整默认配置、安全规则列表及启停、完整命中判决、上下文预算明细和身份/环境模拟仍缺对应接口，未提供无法生效的编辑或模拟操作。

## 前端变更

控制台顶部与安全规则卡片区分已保存检查事件和未接入完整管理能力，移除“尚不包含安全规则命中、上下文预算”的过度概括。页面查询、所有参数及空状态、错误状态保持原样。

补充两条实际页面组合回归规格：可读的策略与上下文事件照常显示且保留完整能力缺口；轨迹读取失败仍显示未知，不捏造命中、预算或假空记录。

## 验证状态

本包仅完成源码与规格编写，机械字节级 Git 应用/反向恢复由独立候选包记录。未执行类型检查、lint、Vitest、构建或 Playwright，未执行数据库或工作流集成验收；须由 CI 专用对话在最终整合代码上验证。本包不具有合并或上线资格。
