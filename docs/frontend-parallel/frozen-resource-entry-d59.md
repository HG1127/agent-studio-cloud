## 对照与实际边界

旧V5.7资源绑定向导强调资源对应真实使用步骤、保存候选后不改已发布版本；发布资源页面另有实时权限和环境白名单。这两类不能混同：当前 AgentManifest 只有模型选择、资料引用数组和流程快照，没有历史资源名称、工具目录、环境授权或当前可用性证据。本页面补齐已冻结版本的只读资源核对及真实所属步骤定位，不造实时目录或授权/执行/审批结果；实时资源与环境缺口仍在接口需求中。

服务端原入口 getVersionExportSource 读取该助手、该版本所属范围内完整 manifest JSON。FrozenVersionPage 直接用 source.manifest 生成 frozenResourceBindingsView，而非 manifest.data 或 frozenWorkflowView 的解析/脱敏投影；只有这个原记录边界证明完整性。原始 manifest、模型/连接/资料标识和指纹不作为新资源组件的客户端属性。传入的本地展示视图只含安全中文、计数和私有所属节点参数，不能保存回原记录。原输入/输出/流程只读视图、版本键重装、返回范围和查询失败/缺失状态不变。

真实 FrozenWorkflowViewer 在客户端内部接同步定位回调，先确认所属节点仍存在于同一冻结节点映射，再选中并聚焦实际详情。内嵌资源仅定位所属顶层步骤；缺失、重复或不可解释的原步骤不补运行层默认标识、不猜第一项。失效归属显示固定中文，不能跳到当前草稿或另一个助手。

布局保持流程画布和步骤详情优先；下方常显模型、资料、工具目录声明摘要，引用长列表用显式展开的原生详情区，默认收起，数量不是执行次数。Root只给新增 FrozenResourceBindings 适配了可选 collapsible，默认false保留原peer展示与原测试；实际父页面传true。原peer两份测试、夹具、辅助函数和交接文件保持原字节。
