# 本页登记字段的手动定位（未验收）

目标前像为冻结1423的实际 d43 前端，独立作者副本不写该树。Own files共7：父页、连接检查和工具目录三份修改；新客户端协调叶子、真实父页组件规格、桌面规格及本文四份新增。

## 真实依据与范围

`src/server/queries/mcp-connections.ts` 将当前远端协议工具的登记标识同时投影为连接标识和核对结果的 `registryToolId`。共享 `McpConnectionCheckResult` 只返回标识、名称、状态，不返回字段快照或指纹。因此唯一标识匹配只允许查看本次页面读取的登记参考说明，不能证明这些字段等于本次远端核对的字段，也不能替代远端定义、实际调用或业务授权。

父页继续使用既有安全查询及 `readToolRegistryDefinitions`。新协调叶子再次使用同一共享契约入口验证当前完整清单，重复、缺项、非法或不可序列化清单不建立定位资格。只有当前目录范围内已经核对的结果行、且其标识精确对应本页唯一完整远端协议定义，才提供“查看本页登记字段”。名称只用于既有展示，不用于查找；标识仅用于内部索引、DOM锚点和契约请求，不进入普通用户文案。

“目录中未找到”“定义已变化”的登记条目也仅作登记参考，不称远端可用。旧结果折叠区不提供定位入口。配置快照完全独立，不参与字段匹配、检查结果或定位资格。

## 读取范围与键盘定位

每次真实父页读取生成内部读取范围；相同字段内容也不能复用上一次页面读取的资格。当前定义内容变化或范围变化会重挂检查和目录实例。目录手动重读先同步撤销资格和定位请求，再沿用原目录加载及批量处置逻辑。成功、失败、重复标识、同标识重读或甲乙甲切换都不能重新借用原页面字段；需“重新读取状态”取得新父页字段读取范围。旧实例布局卸载后不能安排新定位；Strict Mode的效果清理不等于用户重读，不能永久撤销首次有效资格。

定位只响应用户按钮或键盘操作。目录在当前唯一完整定义仍有效时清除遮挡筛选、展开相应业务详情并聚焦摘要，不展开开发者原定义。无排队计时器、后台定位、自动检查或业务调用。定位操作自身不新增网络请求；原有目录GET、配置GET和用户手动检查POST边界保持。
