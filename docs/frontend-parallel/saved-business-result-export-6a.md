# 已保存业务成果导出 6A：独立叶子作者增量

本包只新增服务端导出叶子、浏览器下载按钮、纯展示导出 helper、两份专属规格及本文。未接入 RunDetail；该文件由另一前端增量负责，真实任务详情父级组合与桌面下载路径仍未完成，不声称用户路径已实现。

只读来源是实际 d43 冻结源码，非仅 HEAD 提交。依赖快照及 SHA 记录在独立作者目录 read-only-dependencies 和 read-only-origin.json；任何后续实际组装必须重新核对这些依赖，不能套用旧 V5.7 或旧 d59 作者后端。

导出使用 savedRunResultView 选择当前真实已保存结果，并复用 redactSensitiveData/redactSensitiveText、presentBusinessOutput、runValueLabel 及现有 JSON 可被动读取检查。客户端仅接收最终 MD/CSV 字符串，不接收运行对象、内部字段路径、输入、步骤数据或原始开发者内容。没有新增 query/action、接口、数据库或配置。

仅在明确字段与本次真实关联匹配时隐藏内部引用；已证明的 UUID 身份引用按大小写等价核对，其变体出现在正文或标题时整份停用，不统一删除无关联业务 UUID、数字或归并短步骤名大小写。整步条件来源必须与同次步骤的已保存判断匹配，去向名称必须来自同次实际目标步骤；明确选取条件顶层 next（包括旧式来源步骤.next 路径）时，也必须核对已保存标量与同次源记录，再显示实际目标名称与非完成说明。缺失、错归属、不同判断、步骤不可读或不能解释的正文会停用整份导出，不导出半份，也不把未知说明充当交付内容。非条件及嵌套业务 next/matched 不投射成流程控制。原保存记录、复制按钮和完整 JSON 运行报告不改写。

已有脱敏纯函数最多处理十二层；本地投影预先拒绝会被省略的更深结果，避免把省略标记误当原文。循环、getter、非 JSON 值、非法数量和共享结果字节范围之外的文本同样停用，不降级到原始 JSON。常见脱敏不是完整的数据安全审查。

MD 标题转义为单行，正文包在足够长的纯文本围栏中，保留正文文字而不使其中 HTML/活动链接成为导出结构。CSV 固定三列：记录状态、交付内容、已保存内容；一个交付内容只有一行，复杂对象与列表只是中文展示文本单元格，不生成动态列、不称有业务含义的数据表。CSV 使用中文 BOM、CRLF、双引号及引号转义，前导空白/控制符后的公式标记作中和处理。文件名为固定中文名称，不使用内部编号。

导出状态仅来自实际 RunStatus/RunSourceType。完成状态不等于通过验收；自动验收发起不代表安全模拟、验收通过或外部业务未执行。文件是本页已读取的快照，不再次请求服务器、不保证为最新状态。未添加人工修订、旧版伪验收、重新创建任务或自动重试。

浏览器 API 仅在手动点击中调用。按钮如实提示已发起下载，但无法确认文件是否已保存；失败只提示无法发起下载。URL 在定时回收、来源变化、卸载及失败后尝试释放。服务端叶子按真实任务范围隔离按钮实例，不向客户端新增身份 props；即使两份安全文本相同，切换任务也会清回执并回收旧 URL。来源变化时旧处理不能覆盖新页面回执；渲染、计时器或失败本身不会发起下载。
