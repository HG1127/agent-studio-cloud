# 最小业务助手模板

本线仅开发云版后端，不修改旧 V5.7、页面、模型连接或定时配置。

## 创建与执行

`createMvpAgentAction(input, requestId)` 校验共享 `MvpTemplateInput`，从服务端真实工具登记获取能力，调用纯函数 `buildMvpTemplate`，通过既有 `importAgentAction` 原子保存助手及流程草稿，沿用其请求防重、多租户归属、审计、工具兼容检查。创建动作不调用模型、不发布、不启动，也不执行业务操作。发布与启动继续使用既有发布和启动动作。

流程固定为：接收业务输入 → MCP 只读取数 → 模型结构化方案 → 持久人工审批 → 登记的 HTTP 或 MCP 业务操作 → 既有结果整理节点 → 精确业务回执。人工节点使用已有 Workflow 审批暂停恢复能力，拒绝进入结束路径，返回未获确认结果，不执行业务工具。业务操作使用已有业务操作台账，防重键绑定必填文字输入；重复同一业务必须复用编号，不同业务必须使用不同编号。重新生成方案导致同一编号的参数变化时，由既有台账拒绝冲突，不静默覆盖。

## 必填配置

- 助手名称、业务目标、明确业务规则、审批负责人角色。
- 必填业务输入（名称、中文标签、类型），包含业务防重编号。
- 已登记的 `mcp-streamable-http` 只读取数工具和 HTTP 或 MCP 业务操作工具；业务操作必须声明防重保证及有效期。MCP 必须明确 `operationKind=action`。HTTP 沿用核心登记格式，未填写协议时是 `http-json`，可以不填写操作性质，但不能声明为只读。
- 取数工具顶层参数逐项绑定类型一致的业务输入。
- 数字输入可绑定显式 `number` 或 `integer`，五类业务输入也可绑定登记的联合 `type` 中匹配成员；没有声明类型则拒绝推测。这里仅检查可映射的类型关系，实际值仍由工具冻结和当前登记规则检查。整数参数不接受分数或数字字符串，映射不转换、取整或补兜底值；整数零和布尔否值原样保留。
- 操作工具每个顶层参数逐项绑定 `plan` 中同名的结构化字段；方案字段契约直接取自操作工具登记，不推测工具参数。MCP 使用登记的参数对象；HTTP 使用既有 `action/input/outputs` 封装中的 `input` 对象规则，保留完整封装快照并核对固定动作和空上游成果是否满足登记。
- 最终交付只选择操作工具输出契约中明确必返的顶层字段。

工具地址、鉴权头和凭据只在服务端登记，模板不接受这些字段。模板不接受固定值参数、隐含上游内容、可选来源或兜底值。复杂嵌套参数可作为完整对象字段绑定，本版不拆解嵌套路径。不支持没有明确对象字段契约的工具；缺失工具、规则或映射明确拒绝创建。

创建前会核对本模板派生的完整方案：所有登记参数都必填且不允许额外字段，因此字段数量必须满足原业务参数对象的 `minProperties` / `maxProperties`，原工具的必填项必须在声明字段中。根 `const` / `enum` 若明确限定对象值，至少一个登记值必须通过完整方案校验，否则在保存前拒绝。可选参数仍按本版规则完整映射，工具快照中的原必填列表、数量边界、固定值和枚举保持原样；不补业务值、不放宽工具规则。这些检查覆盖明确冲突，不是任意字段契约的可满足性证明。

HTTP 运行时固定发送 `action/input/outputs` 三个字段。模板先按三个字段核对完整信封的数量边界，再在不填入业务值的部分检查中，将数量上下限扣除必有的 `input` 字段；固定动作与空上游成果仍按原规则检查。部分检查结果不会写回工具快照，嵌套 `input` 的规则独立检查。完整 HTTP 信封的根固定值或枚举没有新增投影支持；没有明确参数字段的只读取数工具（包括空参数对象）仍属于本版已知限制，未在此修复中扩展。

结构化方案保持实际操作参数，不将说明或图片伪装成可执行结果。方案各登记字段均要求返回，使用现有模型输出修复能力；修复失败没有通往业务操作的备用路径。业务规格记录明确用户配置作为需求依据，以及取数回执、方案字段、人工决定、操作回执这些可观察完成标准，不声称这些标准已经执行达成。运行时参数和回执继续接受现有 JSON 契约校验；模型输出失败、审批拒绝或工具回执缺失均不能当作成功。业务规则由方案生成和人工审核遵守，模板没有把任意自然语言规则转换成形式化证明。

最终交付使用共享 `WorkflowOutputField`：`sourceNodeId=execute`、`sourcePath=[登记字段]`，只投影用户选定的回执字段。查询入口 `getMvpTemplateAvailability()` 只返回无地址/凭据的现有登记元数据和配置要求，不进行工具发现或调用。
