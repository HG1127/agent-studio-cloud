# 已保存成果的安全展示

`src/contracts/run.ts` 的 `RunResultValue` 是展示、复制和业务导出共用的成果值边界：完整 UTF-8 JSON 至多两兆字节、32 层、五万个值，只接受普通被动数据；保留零、否定值、空值和历史合法根值。禁止访问器、序列化函数、隐藏属性、循环、保留键和非 JSON 值，不截断正文。它不替换历史 `RunView.result` 的未知值字段，因此坏成果仍可单独提示不可用，不必隐藏整条任务或执行证据。

`redactRunResultData(value)` 位于 `src/server/domain/security/redact-sensitive.ts`，先校验原成果，再按原个人信息与凭据规则处理全部32层，最后核对输出仍符合相同边界。通用上下文仍为12层，结构化仅凭据投影和整份报告35层封套保持原语义，不能互相代用。

个人联系信息、凭据文字和敏感字段继续隐藏；普通 tokenizer、tokenUnit、用量、金额零与否定值保留。秘密本身作为字段名时省略整项，避免重命名覆盖安全字段。结果是新投影，不修改数据库、冻结成果、来源对象或哈希。脱敏占位符使结果超限时明确报不可用，不返回部分内容。

前端接入应统一调用此函数处理实际成果，捕获固定安全错误并只将成果区域标为不可用，保留任务状态及执行证据。不得把错误当作无结果、自动重跑业务或返回未经处理原文。任务详情、验收详情、网页工具成果、复制与业务导出需一起核对；导出的递归与被动 JSON 检查也须采用32层结果边界，并保留原内部关联核对、格式安全和最终文件容量限制。视觉摘要的有意折叠不等于数据截断。

本批只提供后端纯函数、共享契约与测试源码，不改页面或样式。前端接线、实际浏览器、同候选完整检查和默认流 SDK 验收仍需分别完成；源码存在不代表这些验证已通过。
