# 运行执行身份绑定

初始化从 `getWorkflowMetadata().workflowRunId` 获取真实执行身份，缺失或无效时在数据库操作前永久拒绝；不使用直接调用占位身份。排队态转为运行中时，工作区、启动租约、排队状态及执行身份空值或同值条件在同一条更新内检查，同时保存执行身份、开始时间和跟踪版本。租约过期但尚未接管并不撤销原执行者。

运行中重入必须匹配已经保存的执行身份和原租约，只允许补记同一个启动轨迹，不重置开始时间或历史跟踪覆盖。历史运行中但执行身份为空的记录拒绝自动认领，需要核对原引擎及业务操作账本后另行处置；本修复不声称消除旧版本已经放行的未知重叠执行者。

无租约的排队根运行可以初始化。内联协作、交接子运行直接复用父引擎，初始化保存同一个真实执行身份；不增加全局唯一约束，也不创建第二个引擎执行。子运行不会因此获得关闭父默认结果流的权限。

启动回包只在原工作区、原租约、活跃状态及执行身份空值或同值条件成立时保存。保存异常可能发生在提交之后，因此不直接取消或改写业务失败；零行或异常时复读归属，明确记录取消、其他执行身份、新租约接管或未绑定且已失败时，才取消本次迟到句柄。同一执行身份已完成或失败、租约已清除时不取消；复读失败、缺失记录或身份未确认时保留待确认状态。预检失败只能终止未绑定执行者的排队记录。

单元测试覆盖共享契约、纯判定、SQL条件、状态化双执行者竞争、取消和接管、内联子运行与保存结果未知。数据库集成测试使用显式测试元数据，不把直接调用伪装成真实引擎上下文；这些测试须在安全隔离临时库执行，本分支源码实现不等于实际数据库或真实 Workflow 验收通过。

根启动恢复使用同一数据库范围条件：来源只能是手动、定时或评测，父任务为空，执行链归属为空或自身。批量扫描在排序和限额前过滤，单条读取、原子领取、启动预检失败终结及启动回包绑定也使用同一条件；旧协作、交接记录即使缺少父关联和执行链归属，也不能被根恢复独立补启。无租约的旧主任务仍可恢复，内联子任务仍由父引擎编排与初始化；本批不引入独立子引擎模式。

后续工程验收仍包括真实引擎启动响应丢失、初始化和租约接管竞争、取消实际句柄、默认成果持久化与引擎流归属。根恢复的 SQL 条件、零行领取及失败终结路径有普通回归测试源码；子任务保持不变、恢复名额、读后归属竞争与三类主任务恢复另有隔离数据库测试源码，未实际执行前不算数据库或真实 Workflow 验收通过。

需要人工核实的配置：共享数据库配置已经存在，但临时测试项目管理权限、项目归属及新空 `ci_test` 的证据尚未确认。不得复制共享连接串进行清理或迁移，不能由本地单测通过替代隔离库、Workflow、端到端和预览验收。
