- **超过 4MB 的知识原文件**：Vercel Function 请求体上限为 4.5MB，当前上传入口为 multipart 并预留开销，故限制为 4MB；如业务必须上传更大文件，需要配置私有 Blob 并启用客户端直传方案。
- **定时触发入口**：生产环境设置随机 `CRON_SECRET`，并在 Vercel 中确认 Cron 调用携带相同密钥。`vercel.json` 中的每日任务仅用于兜底；系统支持最短 5 分钟间隔，如需按计划时间运行和及时接管启动结果不确定的排队运行，必须另配每分钟一次的外部定时调用，请求 `GET` 或 `POST /api/schedules/tick` 并携带 `Authorization: Bearer <CRON_SECRET>`。单次最多领取 25 条到期任务、接管 5 条超过两分钟仍未确认的排队运行；最多尝试启动 3 次，积压较多时由后续分钟批次继续处理。
